# 2D Plot Builder Interactive v2.1.RC4.b

Программа для построения интерактивных 2D графиков на Python.
Содержит встроенную справку пользователя в формате HTML .

## Основные возможности:
* Графический интерфейс управления (GUI) на Tkinter.
* Построение графиков из файлов в папках `INdoor` и `OUTdoor`.
* Интерактивная работа с графиками .
* Сохранение загруженных логов в обработанном формате ,
  для быстрого повторного построения графиков без статистической обработки .
* Сохранение готовых графиков в виде изображений в папку `Save_plots`.
* Обработка статистики , вывод на экран и сохранение в файл - по частям суток , типу продавца ( бот/человек )
  и гендеру ( на основе имени ) , выделяет топ 5 имен в категориях .

## Как запустить:
1. Установите зависимости (если есть).
2. Запустите файл `main.py`:
   ```bash
   python main.py
